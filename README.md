# Salaries-for-San-Francisco-Employee-Dashboard
Salaries for San Francisco Employees Dashboard is a Power BI project that analyzes city employee compensation, including Base Pay, Overtime, Other Pay, Total Pay, and Total Benefits. The dashboard provides insights into the highest-paying roles, YoY salary growth, department-wise pay trends, and benefits distribution. It features advanced DAX calculations, interactive slicers, multi-page navigation, and a clean, modern UI for effective data storytelling.
This dashboard transforms raw salary records into clear, actionable insights using interactive visuals, DAX measures, and multi-page reporting.

🔍 Key Insights Delivered

✔ Breakdown of Base Pay, Overtime, Other Pay & Total Benefits
✔ Highest Paying Roles & Years based on Total Pay
✔ Year-over-Year Pay Growth % using advanced DAX
✔ Salary range segmentation using Salary Slicer
✔ Department-wise and Job-title-wise compensation trends
✔ Identification of pay gaps, high-benefit roles, and outliers

🛠 Tech Stack Used

Power BI Desktop

DAX (Data Analysis Expressions)

Power Query for Data Cleaning

CSV Salary Dataset – San Francisco City Employees

Multi-page report structure with a clean, modern UI
